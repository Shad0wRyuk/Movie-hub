# 🎬 CineHub

A Netflix-inspired movie streaming frontend built using **HTML5, CSS3, and Vanilla JavaScript**. CineHub delivers a modern cinematic user experience with dynamic content rendering, live search, genre filtering, responsive layouts, and interactive movie detail pages.

## ✨ Features

* 🎥 Dynamic movie and series rendering using JSON data
* 🔍 Real-time search functionality
* 🎞️ Genre-based filtering (Movies & Series)
* ⬅️➡️ Smooth horizontal scrolling navigation
* 🎬 Dedicated movie detail pages
* 🌙 Modern dark-themed UI
* ✨ Interactive hover animations and transitions
* 📱 Responsive design for different screen sizes

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript (ES6)
* JSON
* Bootstrap Icons

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/Shad0wRyuk/cinehub.git
cd cinehub
```

### Run Locally

Because the project loads data from a JSON file, run it using a local server:

```bash
# Python
python -m http.server 5500
```

Open:

```text
http://localhost:5500
```

Or use the **Live Server** extension in VS Code.
